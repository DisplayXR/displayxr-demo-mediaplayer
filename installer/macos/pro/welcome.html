Media Player Pro

A 3D monitoring and review player for stereo productions on glasses-free 3D displays, built on the DisplayXR OpenXR runtime via Vulkan. Shows live stereo inputs and stereo files (side-by-side images and video, ProRes / DNxHR, EXR / DPX / TIFF sequences) with a grade (exposure, ASC CDL, .cube LUT, OpenColorIO), QC views (left / right eye, eye difference, anaglyph), rig checks and snapshots with notes.

Once installed, the app lands at /Applications/Media Player Pro.app, next to the Stereo Media Player if that is installed (the two are separate apps and do not replace each other). Drop a file on the window or pass one on the command line. Full screen is F or a double-click on the picture (macOS keeps F11 for Show Desktop).

Prerequisite: the DisplayXR runtime must be installed first. Download DisplayXR-Installer-*.pkg from the displayxr-runtime releases page. The app bundles its own copy of MoltenVK, the OpenXR loader, FFmpeg and OpenColorIO, but discovers the actual runtime through the system's OpenXR configuration registered by the runtime installer.
